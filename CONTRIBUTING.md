# Contributing

Preserve the one-way translation in `docs/architecture.md`. Do not move endpoint authority, policy, discovery, execution, persistence, migration, or orchestration into `libpkgstate-apply`.

A semantic change requires exact endpoint bodies, typed failure analysis, focused refusal tests, API and manual updates, dependency-closure review, and an explicit release decision. Use C++17, POSIX shell for contracts, and GPL-3.0-or-later SPDX headers.
