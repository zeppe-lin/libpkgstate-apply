# 3.0 extraction

Before 3.0, `libpkgstate-apply` was an optional product in the `libpkgstate` repository and shared its release version with the durable state owner. It is now an independent role-qualified repository with its existing SONAME generation `3` preserved.

No implementation body was synthesized during extraction. The extracted implementation and behavior test remain byte-for-byte identical. Installed declarations differ only by the repository-owned export annotation and export-header include; the extraction contract removes exactly those decorations before checking the original hashes in `libpkgstate-2.5.1-origin.sha256`.
