# 3.0 extraction

Before 3.0, `libpkgstate-apply` was an optional product in the `libpkgstate` repository and shared its release version with the durable state owner. It is now an independent role-qualified repository with its existing SONAME generation `3` preserved.

No implementation body was synthesized during extraction. The repository root preserves the extracted implementation and behavior tests byte-for-byte. Installed declarations differ only by the repository-owned export annotation and export-header include. The extraction contract reads those files from the root commit, removes exactly those decorations, and checks the original hashes in `libpkgstate-2.5.1-origin.sha256`. Later commits are intentionally free to evolve the independent product without falsifying its extraction provenance.
